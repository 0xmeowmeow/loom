# Examples

Each one shows a different thing. Open the **source** modal (Ctrl+E), paste a
file in, and it loads. The comments at the top of each explain what to look at.

| file | shows |
|---|---|
| `01-the-meeting.loom` | **Objects as nodes.** A whole scene made of a table and the things on it. Nothing is a plot beat; the meaning is entirely in what gets picked up and put down. Walk it, then read the story view. |
| `02-empty-nodes.loom` | **Empty nodes and requirements.** Not one node is described — every one was created by an edge pointing at a name. Complete topologically, empty semantically. That's a template. Check the lexicon tab for the computed to-do list. |
| `03-locks-and-loops.loom` | **`->` vs `=>`.** Walk from `arrive`, take the locking edge, and watch the way back go dark. Delete the last edge and watch the status bar complain. |
| `04-dreams.loom` | **Dreams as navigation.** Fragments pulled from where you *haven't* been. Take one branch and the dream tells you about the other. Compare radius 1 to infinite. |
| `05-lexicon-template.loom` | **The lexicon.** Every name is a variable. Change one and it propagates through titles, fragments, actions and requirements at once. Same shape, different story. |
| `06-types-and-shapes.loom` | **The visual vocabulary.** All seven types, shape overrides, and one deliberately wrong edge that connects anyway — dashed and counted, never refused. Try the palettes. |

All six are valid: no dead ends, everything returns, zero parse errors.
`06` has one intentional type mismatch. `02` is intentionally all-empty.
